# BG3 — special requirements and remaining integration work

Updated **5 November 2026** for Windows PC multiplayer. These are selected-mod requirements and researched installation routes, not a mandatory bundle or a compatibility guarantee. Modlane 0.3.17 adds experimental module-PAK switching, original restoration and selected Script Extender setup. Native/loose integrations remain outside this route. See [the preparation guide and tests](BG3_SUPPORT.md).

## Account control is still a required gate

[mod.io's support page](https://support.mod.io/hc/en-us/articles/10641317856655-How-do-I-link-my-Larian-account-to-a-mod-io-account) identifies [the linked-accounts page](https://mod.io/me/account#linked). The [activation guide](https://support.mod.io/hc/en-us/articles/10635137346831-How-do-I-activate-mod-io-in-Baldur-s-Gate-3) distinguishes the in-game sign-in from a website session. Use the supported in-game/account controls in a separately designated test setup, keep Steam online, and retain subscriptions/files. Modlane opens the account page only on the player's click; it does not log in, unlink accounts or edit/revoke game credentials.

Signing out/unlinking is a candidate control, not established prevention: [Larian describes anonymous limited modding access](https://baldursgate3.game/modding-privacy/), and remembered sessions, automatic re-authentication, startup downloads and save/lobby prompts still need controlled observations. The [generic mod.io logout API](https://docs.mod.io/restapi/docs/logout) requires the application's token and cache cleanup; it is not permission or a supported interface for Modlane to read/revoke BG3's credentials.

Account setup records only player observations, scoped to the inspected content and expiring after 24 hours. They never establish actual session state or export trusted compatibility evidence. Experimental launch has a separate fresh confirmation. No offline switch, service-DLL removal, blanket read-only directory or credential-cache deletion is used.

## Experimental route and remaining work

The player approved explicitly labelled experimental launches on 5 November. Each launch requires a fresh signed-out/unlinked confirmation. Remembered Account setup observations do not replace that confirmation or establish prevention. Generic deployment/sharing stay locked.

Implemented: journalled whole-folder moves to a same-volume holding area outside Larian’s game-data roots, verified configuration/tool backups, recovery after restart, drive-space/process/link/ownership checks, original restoration and preservation of unexpected files. Modlane moves the local original collection, rather than copying it across volumes. Library-to-live PAK copies are staged/verified; a linked or unsafe location stops.

Remaining: demonstrate prevention across repeated starts, remembered sessions, host/join/reconnect and mismatch prompts; exact multiplayer runtime/archive reproduction; per-preset saves/settings; native/rendering-aware integrations; real Trials and two-PC acceptance. Developers continue to use only disposable fixtures; the player performs game tests and chooses when to update.
